최종 UI 질문 기능 연결

기존 화면 디자인을 유지하고 agent_db_ui.js를 마지막에 로드합니다.
GET /api/chat/config의 서버 설정으로 DB 질문(/api/chat/db)과 기존 화면 데이터 질문(/api/chat)을 구분합니다.
DB 모드는 question/task_id/history만 전송하며, 업무 목록이나 클라이언트 역할을 권한으로 사용하지 않습니다.
DB 모드를 활성화하려면 AGENT_DB_ENABLED=1, 데이터셋 선택, 서버 DB/모델 환경변수 및 검증된 Slack 세션이 필요합니다.
원문 부재나 권한 오류가 나도 화면 데이터 모드로 몰래 대체하지 않습니다.
답변은 HTML을 실행하지 않는 텍스트/굵게 표시로 렌더링하며 인용 원문의 작성자·시각·메시지 ID·내용을 펼쳐볼 수 있습니다.
질문 업무/모드가 바뀌면 대화 이력을 초기화합니다.

검증: 로컬 Python 31개 테스트 통과, Node 프론트 계약/안전 렌더링/대화 범위/오류 처리 테스트 통과.
최종 UI 자산/질문 API 경로로 실제 모델 응답 1회 성공(약 4.26초, 원문 출처 2개).
이 실행은 실제 DB에서 읽은 복사본과 로컬 테스트 역할을 사용했습니다. 실시간 DB REST/서명 사용자 세션/운영 UI 전체 검증과 구분해야 합니다.
브라우저 자동화가 비활성화돼 있어 시각적 배치와 클릭 동작의 실제 브라우저 QA는 미완료입니다.
운영 사이트 배포/DB 변경은 하지 않았습니다.

로컬 전용 final_local_adapter.js와 DB 복사본/비밀 설정은 배포 파일에 포함하지 않습니다.
